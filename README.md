# Guía Completa de Java - Taller de Programación

Este repositorio contiene la guía y los ejercicios prácticos de Java estructurados por niveles, cubriendo desde los fundamentos de la programación orientada a objetos hasta persistencia y arquitectura.

## 📚 Estructura de Niveles

- **Nivel 01 - Clases, métodos y atributos**: Conceptos básicos de POO, creación de clases, instancias y métodos.
- **Nivel 02 - Encapsulamiento**: Modificadores de acceso, getters/setters y ocultamiento de datos.
- **Nivel 03 - Constructores y sobrecarga**: Inicialización de objetos y sobrecarga de constructores/métodos.
- **Nivel 04 - Herencia y composición**: Reutilización de código, jerarquías de clases y relaciones "es-un" vs "tiene-un".
- **Nivel 05 - Clases abstractas e interfaces**: Contratos, polimorfismo y diseño modular.
- **Nivel 06 - Enum, valores con nombre**: Enumeraciones, constantes con comportamiento y seguridad de tipos.
- **Nivel 07 - Principios SOLID**: Buenas prácticas de diseño de software orientado a objetos.
- **Nivel 08 - Genéricos**: Clases y métodos genéricos, tipado fuerte y reutilización.
- **Nivel 09 - CRUD paso a paso con ArrayList**: Operaciones Create, Read, Update y Delete en memoria.
- **Nivel 10 - Records, datos inmutables**: Uso moderno de Java Records para representar datos inmutables.
- **Nivel 11 - Serialización moderna con archivos**: Persistencia en disco con archivos (`.ser` y `.csv`).
